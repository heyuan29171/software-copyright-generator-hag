# hag — 软著申请材料生成器（MCP Server）

把本地代码项目整理成中国软件著作权登记（**R11**）所需的申请材料，以 MCP 工具的形式暴露给任意支持 MCP 的 agent 客户端调用。

> 状态：**早期实现中**。目前完成了布局层与分页层（61 个测试通过），MCP 工具尚未接线。

## 它做什么

| 产出 | 说明 |
| --- | --- |
| 程序鉴别材料 | 源程序前 30 页 + 后 30 页，每页 50 行，注释与空行剔除 |
| 文档鉴别材料 | 操作手册，前后各 30 页，页码从目录起算 |
| 申请表信息 | 25 个字段值（填报辅助；申请表本体须在官网在线填报） |
| 校验报告 | 逐项 PASS / WARN / FAIL |

## 它不做什么

- **不生成申请表本体**。官方为在线填报，签章页须本人打印签章，程序不得代生成。
- **不代为提交**。
- **不做 R21**（转让合同登记）。
- **不编造代码**。代码材料必须逐行来自真实项目。

## 关键约束（为什么这样设计）

这些不是偏好，是硬要求，见 [`docs/STANDARDS.md`](docs/STANDARDS.md)：

- **每页 50 行**，不是 55。A4 正文区 728.5pt ÷ 14pt 行距 = 52 行上限，55 行物理上放不下。
- **页数取渲染后回读值**，不是理论值。申请表"页数"与实际不符会导致不予登记。
- **切分点只在完整文件边界**，不在函数中间截断。
- **折行在分页之前完成**，否则渲染期换行会悄悄多出一页。
- **不变量失败即中止**，不降级、不猜。
